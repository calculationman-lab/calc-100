# 100問計算RPG v28

v27を基準に「3秒暗記トレーニング」を追加した、ビルド不要の静的PWAです。

## 暗記の遊び方

TOPの「3秒暗記トレーニング」からコースを選びます。初期選択は平方数＋小数と分数のおすすめ70問です。

- 全150問：平方数30、小数と分数40、分数と百分率30、100・1000の組み合わせ20、時間30。
- 1回20問、1問3秒、全問4択。マウス・タップ、キーボードの1〜4で回答できます。
- 正解は約0.3秒、不正解・時間切れは正しい対応を2秒表示します。この時間は次問の3秒に含めません。
- 20問を完了すると正解1出題につき1 EXP（0〜20 EXP）。途中終了ではEXPは付きませんが、回答記録は残ります。
- 不正解・時間切れは3問以上を挟んで再出題されることがあります。再出題も20問の枠内です。
- 「覚えた」は、同じ固定問題に異なる3回の完了した挑戦で正解したときの、4択での目安です。誤答・時間切れで連続成功がリセットされ、その回の解き直しは習得に加算しません。
- 「苦手復習」は誤答・時間切れがあり、まだ覚えていない問題を優先します。少ない場合は同じ分類の確認問題も出ます。
- 「覚えるカード」は時間制限なし。閲覧だけではEXPや習得は増えません。
- アプリ切替・画面非表示では問題を隠して一時停止します。戻ったら「再開する」で残り時間から続けます。
- 操作音ON/OFFは本編と共通。暗記の音が読み込めなくても採点は続きます。

## 保存と既存機能

保存キー `calcRPG` / `calcRPGSettings` を維持しています。暗記は `calcRPG.memoryTraining`（version 1）に保存し、学習記録は最大150問分、暗記履歴は最新40回です。未知の既存フィールドも保持します。

通常100問、今日の完了、クリア回数、ボス条件、装備、連続日数、通常履歴、総計算数のルールはv27のままです。暗記完了で共通EXPだけを加算し、その他の本編進行は増やしません。v27の画像・MP3・HIT配置・装備図鑑を維持しています。数字入力は引き続き無音です。

暗記の完了記録とEXPは一体で保存し、二重加算を防ぎます。保存できないときは未保存と表示し、再試行できます。複数タブの同時学習はWeb Locksで制御します。対応する現行ブラウザとHTTPS、またはlocalhostで利用してください。保護機能が使えない環境では学習開始を止めて案内します。

## ローカル確認

ファイルを直接開かず、HTTPで配信してください。Node.jsがある場合、開発用ソース一式の親フォルダーで次を実行します。

```text
node calc-100-next-dev/serve.cjs calc-100-next 43128
```

確認URL：`http://127.0.0.1:43128/calc-100/`

ほかのアプリと保存・キャッシュが混ざらないよう、専用ポートを使います。通常利用に外部API・DB・ログイン・CDNは不要です。

## GitHub Pagesへの更新

公開先は引き続き `calculationman-lab/calc-100`、URLは https://calculationman-lab.github.io/calc-100/ です。manifestのscope/start_urlは `./` のままです。

1. 公開用ZIPを展開します。ルートに `index.html`、`sw.js`、`memory-*.js`、`memory.css`、`assets/` 等があることを確認します。
2. 既存リポジトリへ展開した中身をフォルダー構造ごとアップロードします。ZIPファイル自体や開発用テストは公開しません。
3. Pages反映後に再読み込みし、必要ならPWAを終了・再起動してTOPの「v28」を確認します。
4. データ保持のため、サイトデータやlocalStorageは削除しないでください。

Service Workerは `calc-rpg-v28`。初回オンライン読込後は本編・暗記・画像・MP3をオフラインで利用できます。

今回の納品ではGitHubへのpush・デプロイは実施していません。

## 同梱資料

- `QUESTIONS.md`：全150問の固定ID・問題・正答。
- `CHANGES_AND_VERIFICATION.md`：変更範囲、検証結果、実機未確認範囲。
- 開発用ソースにはテスト・スクリーンショット・基準v27を別途収録。公開用ZIPにはテスト用依存や学習データを含めません。
