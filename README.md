# 100問計算RPG v30

B案のクリーム色・緑・アプリコット色を使った、縦画面専用の静的PWAです。ビルドや外部APIは不要です。

## 今回の変更

- 指定されたB案画像とホームを比較し、島・勇者・石の台座・周囲の草木を独立パーツで調整しました。点線の進行、ボスのシルエット、ボタンの比率と質感も近づけています。
- iPad mini想定の744×1133、768×1024と、上下バーを想定して高さを小さくした4条件で表示・操作を確認しました。島と進行マークを同じ座標で縮め、勇者の足元が切れない構成です。
- ホーム専用の見た目は `home.css` に分離しています。以下の全画面統一・ルール・保存はv29から維持しています。
- ホーム、通常計算、ボス戦、結果、そうび、装備図鑑、ボス図鑑、記録、遊び方、設定、暗記の全画面を統一しました。
- ボス5体・通常敵5体の画像はv28と同一です。勇者4ポーズ、マップ、通常／ボス背景、装備25点、アプリアイコンを新しく制作しました。
- 背景・人物・装備は独立した画像です。文字・ボタン・ゲージ・図鑑・ナビ・ロゴはHTML/CSS/SVG部品です。
- バージョンはホーム右上の設定に表示します。
- 横向きでは「縦向きにしてね」を表示し、学習の問題・入力を隠して時間を停止します。縦に戻して「再開する」で続けます。アプリ切替時も一時停止します。

端末の向き固定APIとmanifestのportrait指定を使います。API非対応のSafariなどではOS自体の向きを強制できないため、横画面は案内のみになります。横向き用のゲームレイアウトはありません。

## 遊び方

通常は足し算50問＋引き算50問。結果画面で間違いを確認して復習できます。通常100問を3回クリアすると20問のボス戦が解放され、全問正解で100 EXPと防具1個を獲得します。頭・胴・脚・足を揃えると次ランクへ進みます。

3秒暗記は1問3秒・1回20問・4択です。全150問から8コースを選べます。正解は約0.3秒、誤答・時間切れは正しい対応を2秒表示し、その時間は次の3秒に含めません。完了時に正解1出題につき1 EXPを獲得します。カードは時間制限なしで閲覧できます。

通常計算は数字・Backspace・Enter、暗記は1〜4のキーボード入力にも対応しています。数字入力は無音、決定音は設定で切り替えます。

## 保存

保存キー `calcRPG` / `calcRPGSettings` とPWAのURL・scopeを維持しています。レベル・EXP・装備・通常履歴・暗記記録・音設定・未知の既存項目を引き継ぎます。通常／ボス／復習の採点・報酬・出題ルール、暗記の固定問題・期限・習得判定はv28から変更していません。

暗記の完了記録とEXPは一体で保存し、二重加算を防ぎます。暗記で保存できない場合は再試行できます。複数タブの同時学習はWeb Locksで制御します。HTTPSまたはlocalhostと、Web Locks対応ブラウザで利用してください。

## ローカル確認

開発用ソース一式の親フォルダーから起動します。

```text
node calc-100-next-dev/serve.cjs calc-100-next 43128
```

URL: `http://127.0.0.1:43128/calc-100/`

ファイルを直接開かずHTTPで配信してください。他のアプリと保存・キャッシュが混ざらない専用ポートです。横長のPCウィンドウでは向きの案内を表示するため、縦長のウィンドウで確認してください。

## GitHub Pagesへの更新

既存公開先 `calculationman-lab/calc-100` の同じURLに更新できます。公開用ZIPの中身をフォルダー構造ごと置き換えます。ルートには `index.html`、`game.js`、`ui.js`、`ui.css`、`memory-*`、`sw.js`、`manifest.webmanifest`、アイコン、`assets/` などを配置します。ZIPファイル自体や開発用テストは公開しません。

新しいService Workerは `calc-rpg-v30`、事前キャッシュは63項目です。初回オンライン読込後は新画像を含めオフラインで利用できます。公開反映後は再読み込み／PWA再起動を行い、設定画面のv30を確認してください。データ保持のためサイトデータやlocalStorageを削除しないでください。

今回、GitHubへのpush・デプロイは行っていません。
