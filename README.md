# 100問計算RPG v27

現在のアプリバージョン：**v27**

毎日100問の計算に挑戦し、EXP・装備・ボス戦を通して冒険を進めるPWA対応の学習RPGです。

## v27 主な更新

- 戦闘画面の主人公とモンスターを約2倍に拡大
- 主人公とモンスター間の間隔を約2倍へ拡大
- 「1文字削除」を「決定」と同じ文字サイズへ変更
- HIT演出を新しい透過画像エフェクトへ差し替え


- TOP主人公をさらに上寄せし、構図バランスを再調整
- 戦闘画面の敵モンスターを画面中央に配置


- TOP主人公背景を明るいファンタジー風景へ差し替え
- 戦闘画面のテンキー・入力欄・上部情報文字を拡大調整
- 決定時の主人公突進距離を約2倍に強化
- 公開用ファイル構成を assets 配下へ整理済み


- TOP主人公パネルの背景を、新しいファンタジー風景画像へ差し替え
- TOPのロゴ・主人公サイズ・余白バランスを再調整
- 戦闘画面上部のタイトル表示を、TOPと同じロゴ画像へ統一
- 戦闘画面のテンキー・問題文・入力欄・上部情報の文字サイズを拡大調整
- 画面高さが低いPC/iPad横画面でも、テンキー下部まで表示しやすいよう再調整
- 決定時の斬撃エフェクトと同時に、主人公が一瞬前へ踏み込んで戻る攻撃演出を追加
- 装備画像を `assets/equipment/` へ移動し、公開用ファイル構成を整理
- ユーザー提供の最新 `confirm.mp3` を引き続き使用
- APP_VERSION / TOP表示 / Service Worker を **v27** に統一

## 保存データ

既存の `calcRPG` と `calcRPGSettings` を維持しているため、これまでの進行データを保持したまま更新できます。

## 公開

GitHub Pages 用。既存の `calc-100` リポジトリへ上書きアップロードして使用します。


### v27 追加修正

- HIT画像を敵モンスターと同じ座標・同じ表示領域の中央へ配置
- HIT画像はモンスターより少し小さいサイズに調整
- 装備図鑑の「GET」文字表示を廃止
- 入手済み装備を実際の装備画像・装備名・所持数で表示
- 未入手装備はシルエットと「？」、未解放ランクは未解放表示
- 既存セーブデータ・装備獲得ロジックを維持
