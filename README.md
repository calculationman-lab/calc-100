# 100問計算RPG 機能最終回帰テスト版

GitHub Pagesへフォルダー内のファイルをそのまま配置できます。サーバー、API、ビルド作業は不要です。

- 「今日の100問をはじめる！」を各画面幅で1行表示
- PC上段3パネルの高さを統一
- 装備カードを部位名・画像・装備名・状態の縦構成へ統一
- 「現在装備」と「防具コンプリート」を分けて表示
- Lv、EXP、冒険日数、総計算数、連続ボーナス、ボス進行、装備、最近の記録を保存データから表示
- 装備5枠、ランク進行、メニュー、ボス案内、ルールを独立した部品として実装
- 添付の冒険者画像をTOPとPWAアイコン（180/192/512）へ反映
- `calcRPG` localStorageキーと既存データ形式を維持し、不足フィールドを補う後方互換処理を追加
- 通常・ボス・誤答復習を別セッションとして管理し、復習による二重進行を防止
- TOPに「今日の100問：完了／未完了」を表示
- 革の脚装備を茶色い革ズボンのピクセルアートへ差し替え
- 装備ランクごとの専用ボス5体、動的TOP表示、ボス図鑑、個別討伐数を追加
- ボス戦開始時の相手を固定し、討伐履歴へ `bossId`・`bossName`・`tier` を保存
- 数字・決定・戻る操作へ軽量なWeb Audio戦闘音を追加（通常戦とボス戦で音色を変更）
- 数字・決定操作へ短いHIT／斬撃演出、決定操作へ1～3pxの画面揺れを追加
- TOPへ「操作音 ON/OFF」を追加し、`calcRPGSettings` へ独立保存
- iPad内蔵スピーカー向けに戦闘音をAttack・Body・Noiseの3層へ再設計
- Master GainとDynamics Compressorを追加し、瞬間的な音圧とクリップ耐性を強化
- 提供MP3「剣で斬る1」を数字音、「剣で斬る6」を決定音として無加工採用
- 通常敵5体と、問題進行に連動して減る敵HPバーを計算画面へ追加
- ボス戦では装備tier対応の既存ボス画像・名前を計算画面へ表示
- Service Workerキャッシュを `calc-rpg-v13` に更新し、MP3と通常敵画像をオフライン対象へ追加

## 操作音・戦闘演出

- 数字キー：30～60ms程度の控えめな軽い攻撃音
- 決定キー：通常より少し強い攻撃確定音
- 戻るキー：短く低い操作音
- ボス戦：通常戦より少し低く重い音と、わずかに強い斬撃・揺れ
- 復習：通常戦と同じ音

音はWeb Audio APIで端末内生成するため、外部URLや音声ファイルを使用しません。音・演出は入力操作だけに連動し、正答と誤答で一切変化しません。iOS/iPadOSではユーザー操作時にAudioContextを安全に再開し、再生できない場合も回答処理は継続します。端末のマナーモードや音量設定による実際の聞こえ方はOS側の挙動に依存します。

### 音圧強化 before / after

| 操作 | 旧単音Gain | 新Attack | 新Body | 新Noise |
|---|---:|---:|---:|---:|
| 通常数字 | 0.014 | 0.10 | 0.045 | 0.035 |
| 通常決定 | 0.024 | 0.18 | 0.11 | 0.07 |
| ボス数字 | 0.023 | 0.15 | 0.09 | 0.06 |
| ボス決定 | 0.032 | 0.25 | 0.16 | 0.10 |
| 戻る | 0.012 | 0.085 | なし | なし |

各SEは `Attack / Body / Noise → Master Gain 0.78 → Compressor → destination` の共通経路を使用します。通常数字は約52ms、通常決定は約85ms、ボス数字は約65ms、ボス決定は約115msで、再生終了を待たずに次の回答処理を進めます。

### MP3正式音源とフォールバック

- `assets/sounds/digit.mp3`：提供ファイル「剣で斬る1.mp3」の無加工コピー。数字0～9で使用
- `assets/sounds/confirm.mp3`：提供ファイル「剣で斬る6.mp3」の無加工コピー。決定で使用
- MP3正常時はWeb Audio生成音を重ねません
- 読込・再生失敗時だけ、上記のWeb Audio音へフォールバックします
- 4個のAudio poolを再利用し、連打のたびに先頭から非同期再生します
- 戻るキーは従来どおりWeb Audio生成音です

MP3を同じファイル名で置き換えれば、コード変更なしで数字音・決定音を差し替えられます。将来のボス専用MP3も音源マップへ追加できる構造です。

## 敵HP・モンスター表示

- 通常100問：開始時`HP 100 / 100`、回答ごとに1減少、完了時`0 / 100`
- ボス20問：開始時`HP 20 / 20`、回答ごとに1減少、完了時`0 / 20`
- HPは正誤ではなく回答済み問題数だけで減ります
- 通常戦・復習では、アクアスライム、森のゴブリン、シルバーウルフ、ナイトバット、どくキノコからセッション開始時に1体を選びます
- ボス戦では革・石・鉄・ダイヤ・ネザライトに対応する既存ボスを表示します

## EXP正式仕様

- 通常100問完了：基本100 EXP
- 0～89点：追加なし
- 90～94点：+20 EXP
- 95～99点：+30 EXP
- 100点：+50 EXP
- 2日連続：+10 EXP
- 3日連続：+20 EXP
- 4日連続：+30 EXP
- 5日連続：+40 EXP
- 6日連続以上：+50 EXP（上限）
- ボス20/20撃破：+100 EXP
- 誤答復習：EXPなし

連続ボーナスはパーセントではなく固定EXP加算です。休んでもEXP、レベル、装備、ボス進行は減りません。

## セッションと総計算数

- 通常100問完了：総計算数+100、通常履歴を保存
- 通常問題の途中離脱：加算・保存なし
- 誤答復習：実際に最後まで回答した復習問題数だけ加算。EXP、クリア回数、ボス進行、通常履歴は増えません
- ボス20/20成功：総計算数+20、ボス成功履歴を保存
- ボス失敗：従来仕様を維持し、総計算数と履歴には加算しません。ボス出現状態は維持します
- ボス再挑戦：誤答だけではなく、新しい20問すべてに再挑戦します

同じ日に通常100問を複数回完了できます。各回でEXP、クリア回数、ボス進行、履歴が加算されますが、冒険日数は1日です。TOPの今日の完了表示には当日の最新結果を表示します。

## 保存データ

保存キーは従来どおり `calcRPG` です。更新時に保存データを削除しないでください。

`bossWins` がない旧データは、過去履歴から推測せず各ボス0体として安全に補完します。既存のEXP、クリア回数、装備、履歴はそのまま維持されます。

## 自動テスト

Node.jsがある環境では次を実行できます。

```text
node tests/smoke-test.js
node tests/regression-test.js
node tests/boss-tier-test.js
node tests/sound-effects-test.js
node tests/sound-pressure-test.js
node tests/mp3-hp-enemy-test.js
```

回帰テストはEXP・レベル境界、連続ボーナス、復習、ボス、全防具ドロップ、重複、全ランク解放、日次完了、履歴、途中離脱、旧セーブ互換を検証します。ボスランク試験は5体の対応、討伐記録、失敗時非加算、戦闘開始時固定、ランクアップ表示、図鑑を検証します。音・演出試験は初期設定、保存、各キーの音ルート、OFF時のAudio非生成、正誤同一音、DOM再利用を検証します。音圧試験は相対Gain、3層構成、Master/Compressor、OFF、review、正誤同一プロファイル、非同期非待機を検証します。MP3・HP・敵試験は指定音源経路、二重再生防止、fallback、pool、HP境界、通常敵固定、tierボス、v13キャッシュを検証します。
